
# 𓆩♡𓆪 Activity 5: AI Tools Activity

## 𓇢𓆸 Activity Description

This activity focused on exploring the use of artificial intelligence tools through prompt creation and refinement. I chose **ChatGPT** as my AI tool to generate an image of a wedding feast table. I first provided a simple prompt and then improved it with the help of a leading language model (LLM) by adding specific food preferences, decorations, colors, and lighting details. I also compared the two generated images to determine how the improved prompt influenced the final output in terms of accuracy, personalization, and detail.

## 🦢 What Have I Learned?

Through this activity, I learned that the quality of an AI-generated output depends greatly on how clearly and specifically a prompt is written. I discovered that adding relevant details, such as the desired food, theme, colors, and overall atmosphere, helps the AI generate results that better match my ideas. One challenge I encountered was getting the generated image to accurately represent all the details in my improved prompt, since some food items and labels were still not perfectly rendered. By refining my instructions and providing more context, I was able to achieve a more personalized result. Moving forward, I can apply these skills when using AI tools for creative projects, visual planning, and other tasks that require clear and effective prompting.
