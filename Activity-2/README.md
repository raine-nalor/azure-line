
# 𓆩♡𓆪 Activity 2: Personal Branding

## 𓇢𓆸 Activity Description

This activity focused on developing my personal brand by creating a visual identity that represents my style and personality. It involved selecting a consistent color palette and typography, designing a personal logo, creating a resume header, and coming up with a personal tagline. These elements served as the foundation of my overall design style, which I aimed to maintain throughout my succeeding activities and my GitHub portfolio, Azure Line.

## 🦢 What Have I Learned?

Through this activity, I learned that personal branding is more than just choosing colors and creating a logo; it is about building a recognizable and consistent identity. I realized the importance of selecting colors and fonts that complement each other and using them consistently across different platforms and materials. One challenge I encountered was choosing design elements that worked well together while still reflecting my personal style. I addressed this by establishing a color palette, typography, and visual elements that I could use as a guide for my future projects. Moving forward, I can apply this foundation to maintain a cohesive visual identity in my academic outputs, digital projects, and professional materials.
