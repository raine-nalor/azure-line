
# 𓆩♡𓆪 Activity 6: Website Development – SafeSex PH

## 𓇢𓆸 Activity Description

This activity involved developing a one-page advocacy website using an AI-assisted website-building tool. I chose **SafeSex PH: Know the Facts. Protect Your Future.** as my website concept, which aims to promote sexual health awareness among Filipino college students and young adults. The website covers important topics such as safer sex, sexually transmitted infections (STIs), HIV prevention, contraception, consent, and available Philippine health resources. Using AI-assisted website development, I created a responsive and interactive platform designed to present accurate health information in an accessible and engaging way.

## 🦢 What Have I Learned?

Through this activity, I learned how AI tools can assist in developing websites and transforming ideas into functional digital platforms. I gained experience in writing detailed prompts, selecting design elements, organizing website content, and incorporating interactive features. One challenge I encountered was ensuring that the website presented a wide range of health information while remaining organized, understandable, and visually appealing. I addressed this by providing specific instructions for the website's layout, color palette, typography, and content. Moving forward, I can apply these skills to create more informative websites and explore how technology can support health education, advocacy, and public awareness.
