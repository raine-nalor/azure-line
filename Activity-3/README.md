
# 𓆩♡𓆪 Activity 3: Infographic and Project Documentation

## 𓇢𓆸 Activity Description

This laboratory activity focused on presenting a real-world problem through visual communication and proposing a technology-based solution. For my chosen topic, **BRIDGE: A Resource Information System for Organizations Supporting Afghan Women**, I explored the challenges surrounding access to resources and support for Afghan women. The activity involved creating a one-page infographic to simplify and communicate relevant information, as well as preparing a project documentation report proposing an IT-enabled solution. Through these outputs, I applied information synthesis, data simplification, visual storytelling, and project documentation skills.

## 🦢 What Have I Learned?

Through this activity, I learned how technology can be used to address real-world problems and improve access to important information and resources. I gained experience in gathering relevant information, identifying key points, and presenting them in a simplified and visually engaging way. One challenge I encountered was organizing complex information about the situation of Afghan women into content that was clear, concise, and easy to understand. I addressed this by identifying the most relevant details and arranging them logically in both the infographic and project report. Moving forward, I can apply these skills when developing digital solutions, creating informative materials, and communicating ideas that address meaningful social issues.
