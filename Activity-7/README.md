
# 𓆩♡𓆪 Activity 7: Resume Generation Using AI Tools

## 𓇢𓆸 Activity Description

This laboratory activity focused on exploring how different Large Language Models (LLMs) generate professional documents using the same set of instructions. I used **ChatGPT and Gemini** to create one-page professional resumes based on my personal information, educational background, and work experience. After generating both outputs, I compared them based on structure, clarity, formatting, and overall quality to identify their strengths and weaknesses and determine which version was more suitable for a professional nursing application.

## 🦢 What Have I Learned?

Through this activity, I learned that different AI tools can produce varying results even when given the same information and instructions. I noticed that ChatGPT focused more on visual presentation, while Gemini provided a simpler and more traditional resume layout. Comparing the two outputs helped me understand the importance of choosing a format that is appropriate for the intended purpose and audience. One important realization was that AI-generated content should not be accepted immediately without reviewing its accuracy, completeness, and presentation. I personally preferred Gemini's output because I found it more professional and easier to read for an entry-level nursing application. Moving forward, I can use AI tools as a starting point when creating professional documents while still applying my own judgment to ensure that the final output accurately represents my qualifications.

## 𓇢𓆸 AI Tools Used

- **ChatGPT** – Generated a resume with navy blue accents, icons, and decorative elements.
- **Gemini** – Generated a more traditional and straightforward resume layout.

## 🦢 Comparison Summary

| Criteria | ChatGPT | Gemini |
|:---|:---|:---|
| Structure | Organized sections and logical arrangement | Separate sections for training and certifications |
| Clarity | Readable descriptions and visible headings | Concise and easy to scan |
| Formatting | Navy blue accents, icons, and decorative elements | Clean and traditional layout |
| Overall Quality | Visually attractive but slightly crowded | Professional and practical for nursing applications |

**Preferred Output:** Gemini, because its straightforward and professional layout is more suitable for an entry-level nursing application.
